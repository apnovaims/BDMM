# Big Data Modelling and Management — Airbnb Analysis

Document-oriented data modelling and business analysis over the Airbnb dataset, using MongoDB aggregation pipelines from Python.

Course project for Big Data Modelling and Management, MSc in Data Science and Advanced Analytics, NOVA IMS.

## What the project does

- Models Airbnb data as documents in MongoDB.
- Answers business questions with aggregation pipelines and document queries.
- Analyses fields across collections.
- Runs against a containerised MongoDB instance in Docker, queried with PyMongo.
